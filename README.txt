iwant2gohome - 출근시간 자동 기록 + 퇴근 타이머 위젯 (Windows)

[설치]
(위젯이 두 개 겹쳐 보이면: install.bat 을 다시 실행하세요. 예전 버전이 남아 있으면 자동으로 정리됩니다.)
1. 압축을 풀고 install.bat 을 더블클릭하세요. (관리자 권한 필요 없음)
2. 바탕화면 오른쪽 아래에 위젯이 나타납니다. 이후 로그인할 때마다 자동 실행돼요.
   ※ 설치한 날은 설치한 시각이 출근시간으로 기록됩니다. 위젯을 우클릭 > '출근시간 수정'으로 고치세요.

[위젯]
- 출근시간 + 9시간 = 퇴근시간 (금요일은 + 8시간). 퇴근까지 남은 시간이 초 단위로 줄어듭니다.
- 단계가 시간에 따라 자동으로 바뀝니다: 출근~11:30 '점심까지' → 11:30~12:30 '식사 중' → 12:30~퇴근 '퇴근까지' → 퇴근 후 '야근 중'
- 0:00:00이 되면 '야근 중'으로 바뀌고, 배경이 밤하늘(달)로 바뀌면서 야근 시간이 올라갑니다.
- 캐릭터 옆 말풍선에 상태와 한마디가 나오고, 진행률(%)은 진행 바 위에 표시됩니다.
- 진행 바 위의 8비트 개발자(회색 후드티)가 15분마다 행동을 바꿉니다. (일하기 / 커피 / 산책 / 졸기) 야근 중에는 졸거나 커피를 마시는 시간이 늘어요. 퇴근 시각이 되는 순간에는 잠깐 환호합니다.
- 알림음은 없습니다.
- 위젯은 바탕화면에만 떠 있고, 다른 창을 띄우면 그 창 아래로 가려집니다. (Win+D 로 바탕화면을 보면 다시 보여요)
- 화면 배율(125%, 150% 등)에 맞춰 크기가 자동으로 조절됩니다.
- 새벽 4시 전까지는 전날 근무(야근)로 계산합니다.

[날씨 배경]
- 실시간 날씨(Open-Meteo, 로그인/키 불필요)에 따라 낮 배경이 맑음(해) / 구름 조금 / 흐림 / 비 / 눈 / 천둥으로 바뀝니다. 30분마다 갱신.
- 회사 보안으로 막히면 api.open-meteo.com 접속을 허용해야 합니다. 안 되면 기본 맑은 하늘이 표시되고 error.log 에 기록돼요.
- 위치 기본값은 부산입니다. 문서\출근기록\settings.ini 의 lat / lon 값을 고치면 바뀝니다. (우클릭 > 날씨 효과 로 끄고 켤 수 있어요)

[출근시간 기준]
- 기본: 그날 첫 키보드·마우스 입력 시각입니다. 컴퓨터를 켜 둔 채 자더라도, 새벽 4시 이후 처음 마우스를 움직이거나 키를 누른 시각이 출근시간이 됩니다.
- 우클릭 > 출근시간 기준 에서 '컴퓨터 부팅 시각'으로 바꿀 수 있습니다.
- 그날 이미 기록된 값은 기준을 바꿔도 유지됩니다. 틀리면 '출근시간 수정'으로 고치세요.

[캐릭터 선택]
- 위젯을 한 번 왼쪽 클릭(끌지 않고)하면 캐릭터 선택창이 뜹니다. (우클릭 > 캐릭터 선택 도 가능)
- 개발자(회색 후드티) / 여자1(히피펌 커리어우먼: 통화·벽 샌드백·커피·고양이·졸기·퇴근 중 15분마다 랜덤)

[자체 업데이트]
- 업데이트 주소는 기본으로 들어 있어서 따로 설정할 필요가 없습니다. (바꾸려면 우클릭 > '업데이트 주소 설정…')
- 이후 켤 때와 6시간마다 새 버전을 확인하고, 있으면 '지금 업데이트할까요?' 창이 뜹니다. [예]를 누르면 그 자리에서 새 버전을 만들어 교체하고 위젯이 자동으로 다시 켜집니다. (재설치 불필요)
- 수동 확인: 우클릭 > '업데이트 확인…'
- 배포하는 쪽: 새 iwant2gohome.cs 와, 코드 안 Version 숫자보다 큰 숫자가 적힌 version.txt 를 같은 폴더에 올리면 됩니다.

[위치·크기]
- 위젯을 마우스 왼쪽 버튼으로 끌면 원하는 곳으로 옮길 수 있고, 위치는 기억됩니다.
- 크기: 오른쪽 아래 모서리를 끌거나, 위젯 위에서 마우스 휠을 돌리거나, 우클릭 > 크기 에서 고릅니다. (50%~300%)
- 우클릭 > 위치·크기 초기화 로 처음 상태(오른쪽 아래, 100%)로 되돌립니다.

[우클릭 메뉴]
- 출근시간 수정 / 출근시간 기준 / 크기 / 위치·크기 초기화 / 투명도(100%~30%, 기억됨) / 날씨 효과 켜기·끄기 / 최소화(트레이로) / 기록 폴더 열기 / 종료
- 최소화하면 위젯이 사라지고 작업표시줄 오른쪽 트레이에 아이콘이 생겨요. 아이콘을 누르면 위젯이 다시 나타납니다.

[출근 기록]
- 하루 첫 실행 시각(부팅 시각이 오늘이면 부팅 시각)이 문서\출근기록\출근기록.csv 에 날짜 / 요일 / 출근시간으로 쌓입니다. 엑셀로 열 수 있어요.

[삭제]
- uninstall.bat 실행 (기록 파일은 남습니다)

[안 될 때]
- 문서\출근기록\error.log 가 생기면 내용을 알려주세요.
- install.bat 에서 Build failed 가 나오면 그 화면을 알려주세요. (회사 보안 설정으로 컴파일이 막혔을 수 있어요)

[참고]
- 점심/퇴근 버튼 제거. 시간에 따라 자동 전환:
  출근~11:30 "점심까지" → 11:30~12:30 "식사 중"(밥 먹는 모습, 따뜻한 배경) → 12:30~퇴근 "퇴근까지" → 퇴근 후 "야근 중"
- 진행률(%)은 진행 바 바로 위에 작게 표시. 캐릭터 옆 빈 공간에는 상태와 한마디가 텍스트로만 나옵니다.
- 배경은 흰색 대신 하늘색(낮) / 살구색(식사) / 남색(야근).
